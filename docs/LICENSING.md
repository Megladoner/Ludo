# Asset and dependency licensing

The initial application uses original project-authored HTML, CSS, JavaScript, SVG iconography, and generated board geometry. It does not bundle third-party images, fonts, sound recordings, or npm packages. Typography falls back to locally installed system fonts. The project has no third-party runtime dependencies, so there are no npm package licenses to reproduce in this build.

Before adding external fonts, icons, illustrations, audio, or packages, record their source, license, version, and required attribution here.
